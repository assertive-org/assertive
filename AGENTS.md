## Lugh consumer skills

This repository uses Lugh to publish consumer-facing agent skills from `.lugh/skills`. Treat those skills as part of the package's public interface.

After changing public APIs, configuration, installation, examples, or recommended usage, review the affected consumer skills and keep them up to date. Use the `lugh-skill-authoring` project skill for the maintenance workflow.
